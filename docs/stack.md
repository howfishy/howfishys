# Stack

## Core
- Astro — version 6.3.1
- Node.js — v24.1.0 
- Vanilla JS — no framework in the browser

## Tools
- VSCodium — primary editor
- Roo Code — agentic coding extension (installed)
- Gemini 2.5 Flash — AI model via Google AI Studio free tier (installed)
- Context7 MCP — live documentation fetching 
- Aseprite — pixel art and sprite animation (installed)
- Git 2.49.0
- Homebrew — package manager

## Hosting
- GitHub Pages — static hosting
- GitHub Actions — automatic deployment on push to main

## Typography
- Tufte CSS — sidenotes and reading typography

## Asset format
- PNG sprite sheets — pixel art, image-rendering: pixelated
- HTML files — exported Plotly charts, embedded via iframe

## Browser APIs used
- Date (getHours, getMonth) — time of day and season system
- localStorage — season state persistence across visits
- Geolocation API — not used (dropped in favour of local time)
